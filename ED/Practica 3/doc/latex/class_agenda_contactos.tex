\doxysubsection{Detailed Description}
TDA \doxylink{class_agenda_contactos}{Agenda\+Contactos}. 

Gestiona un conjunto de contactos identificados por su nombre y permite buscar contactos por etiquetas.

La estructura principal es un map (nombre -\/\texorpdfstring{$>$}{>} \doxylink{class_contacto}{Contacto}) y se mantiene un índice auxiliar con un multimap (etiqueta -\/\texorpdfstring{$>$}{>} nombre\+Contacto) para obtener rápidamente los contactos asociados a una etiqueta.

Invariante de representación\+:
\begin{DoxyItemize}
\item lista\+Contactos asocia cada nombre con un \doxylink{class_contacto}{Contacto} válido.
\item etiquetas contiene pares (etiqueta, nombre) coherentes con las etiquetas almacenadas en los Contactos de lista\+Contactos.
\end{DoxyItemize}

Función de abstracción\+:
\begin{DoxyItemize}
\item El objeto \doxylink{class_agenda_contactos}{Agenda\+Contactos} representa una agenda de contactos donde cada contacto tiene teléfonos, correos y etiquetas, y es accesible por su nombre. 
\end{DoxyItemize}
