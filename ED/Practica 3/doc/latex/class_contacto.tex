\doxysubsection{Detailed Description}
TDA \doxylink{class_contacto}{Contacto}. 

Representa un contacto de una agenda identificado por un nombre y que contiene un conjunto de teléfonos, correos electrónicos y etiquetas asociadas.

Invariante de representación\+:
\begin{DoxyItemize}
\item El nombre identifica de forma única al contacto.
\item No existen teléfonos duplicados.
\item No existen correos duplicados.
\item No existen etiquetas duplicadas.
\end{DoxyItemize}

Función de abstracción\+:
\begin{DoxyItemize}
\item El objeto \doxylink{class_contacto}{Contacto} representa a una persona con un nombre y varios datos de contacto (teléfonos, correos y etiquetas). 
\end{DoxyItemize}
