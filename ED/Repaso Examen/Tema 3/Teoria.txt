------------------- TEMA 3 -------------------


1.¿Qué es un Tipo de Dato Abstracto (TDA) lineal?

---> Es un TDA cuyos elementos están organizados de forma secuencial y hay relacion de orden lineal entre ellos.


2.¿Qué características definen a una lista como TDA lineal?

---> Una lista es un TDA formado por una secuencia ordenada de elementos en el cual todos los elementos tienen siguiente y anterior.


3.¿Cuáles son las operaciones básicas de una lista?

---> Construir/Vaciar la lista, saber si está vacía, su cantidad de elementos, insertar o eliminar un elemento, conocer elemento de una posicion, conocer la posicion siguiente, anterior, primer y ultima de la lista y copiar 2 listas.


4.¿Qué se entiende por posición en una lista?

---> El lugar de un elemento dentro de la lista.


5.¿Qué ventajas aporta el uso de una clase Posición frente a usar índices enteros?

---> Evita dependencias de los índices, mejora la seguridad y su reutilización. Además ayuda al movernos sobre la lista.


6.¿Qué diferencias existen entre una lista implementada con vector y una lista implementada con celdas enlazadas?

---> Vector: Los elementos están contiguios de memoria y el acceso es directo.
---> Celdas: Estan dispersos, pero todos los elementos estan enlazados con su siguiente y se accede desde cada celda a la siguiente.


7.¿Cuáles son las ventajas e inconvenientes de las listas enlazadas frente a las listas con vector?

---> Insercion y borrados más eficientes (ya que solo cambiamos los punteros de las celdas), pero tiene acceso secuencial y en general hay mayor uso de memoria.


8.¿Qué es una lista doblemente enlazada y qué ventajas tiene sobre una simplemente enlazada?

--->  Tiene enlaces al elemento siguiente y anterior, permite recorridos en ambos sentidos y borrados mucho más eficientes.


9.¿Qué es una cola y qué política de acceso sigue?

---> Es similar a una lista, pero solo se puede ver el primer elemento que se ha introducido (FIFO)


10.¿Cuáles son las operaciones básicas de una cola?

---> Crear,vaciar, añadir o elimar, consultar primero, comprobar si está vacia y copiar 2 colas.


11.¿Qué diferencias existen entre cola y pila?

---> Las colas son FIFO y las pilas son LIFO.


12.¿Qué es una pila y qué política de acceso sigue?

---> Una pila es un TDA en la que solo se puede acceder al ultimo elemento que se ha insertado. 


13.¿Cuáles son las operaciones básicas de una pila?

---> Construir/Vaciar la pila, saber si está vacía, el numero de elementos y su máximo, insertar/eliminar el último elemento de la fila, copiar dos pilas.


14.¿Qué ventajas tiene implementar una pila o cola a partir de una lista?

---> Pues que reusaremos el código de la lista usando las funciones de esta, además mantendremos la abstracción.


15.¿Qué es una cola circular y por qué se utiliza?

---> Es una cola hecha a partir de un vector en la cuál el ultimo elemento se conecta con el primero para reutilizar posiciones libres.


16.¿Qué ventajas tiene una implementación con vector circular frente a un vector normal?

---> Evita desplazamientos de elementos y aprovecha mejor la memoria disponible.


17.¿Qué es un vector dinámico?

---> Un vector que puede cambiar de tamaño si es necesario.


18.¿Qué es un vector disperso?

---> Un vector en el que la mayoría de elementos son cero/vacios, y se almacenan solo los valores significativos


19.¿Qué es un conjunto como TDA lineal?

---> Es un TDA que almacena elementos sin repetición y sin importar el orden,de elementos del mismo tipo.


20.¿Qué aplicaciones típicas tienen las pilas?

---> Evaluar expresiones, llamar a funciones, recursividad.


21.¿Qué aplicaciones típicas tienen las colas?

---> Gestion de procesos, simulaciones, atención por turnos.


22.¿Cómo se puede utilizar una pila para detectar palíndromos?

---> Fijandonos en el recorrido que hace la cadena al desapilar.


23.¿Cómo se puede transformar un algoritmo recursivo en uno no recursivo usando pilas?

---> Haciendo que una pila simula otra pila de llamadas a funciones, llamandolas de forma externa por decirlo de alguna forma.


24.¿Qué ventajas tienen los TDA lineales frente al uso directo de estructuras básicas del lenguaje?

---> Independencia en su implementación, claridad, reutilizacion de código, de forma que le podemos dar las funcionalidades que queramos.


25.¿Qué implementación elegirías para una lista si necesitas muchos accesos aleatorios y por qué?

---> Lo suyo sería una lista a partir de un vector, ya que aprovechamos los índices, haciendo que el acceso sea directo y rápido.


26.¿Qué implementación elegirías para una lista si necesitas muchas inserciones y borrados y por qué?

---> Una lista a partir de celdas enlazadas, para no tener que estar desplazando elementos o redimensionando el vector.
