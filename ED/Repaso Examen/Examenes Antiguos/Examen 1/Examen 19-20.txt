EJERCICIO 1

a. Enumera y explica suficientemente los tipos de métodos que hay para medir la 
eficiencia de un algoritmo y compara las ventajas y desventajas entre ellos.

    Hay 3 tipos, empírico, teórico y hibrido.

    Empírico: Refleja el comportamiento real del algoritmo, pero hay que programarlo y depende del sistema, maquina, compilador, etc.

    Teórico: Es independiente del lenguaje o maquina y no hay que programarlo, pero, no tiene en cuenta constantes ni otros detalles de la implementación.

    Hibrido: Es una mezcla que aprovecha las ventajas de los 2 anteriores.

c. Dado el siguiente algoritmo:

    int Busqueda(const int v[ ] ,int n,int x) {
        int izq=0,der=n−1;
        int centro;

        while(izq<=der) {
            centro= (izq+der)/2;

            if(x<v[centro] )
                der=centro−1;
            else if(x>v[centro] )
                izq=centro+1;
            else return centro;
        }
            return−1;
    }

¿Que eficiencia tiene el método? ¿Por qué?

    if/else -> O(1) o O(n)

    while -> O(1)

    Es el método de busqueda -> O(log n)

    Respuesta final: Dependiendo de si las asignaciones son grandes sería O(log n) o O(n * log n)
