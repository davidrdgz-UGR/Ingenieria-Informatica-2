2. (1,5 puntos) Responde a las siguientes preguntas relacionada con la eficiencia de
algoritmos:
    a. (1 punto) Dado el siguiente algoritmo de búsqueda:
    
    int binarySearch(int arr[], int size, int target) {
        int left = 0, right = size - 1;
        
        while (left <= right) {
            int mid = left + (right - left) / 2;
            
            if (arr[mid] == target) {
                return mid; // Elemento encontrado
            } else if (arr[mid] < target) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return -1; // Elemento no encontrado
    }

¿Qué eficiencia tiene el método teniendo en cuenta el peor caso? ¿Por qué?
¿Cuál sería el mejor caso? Explica que situación se daría y qué eficiencia sería.

    Mejor caso O(1), peor caso O(log n)

b. (0,5 puntos) Si el algoritmo anterior lo programo en Java, ¿Será más rápido que el
proporcionado en C++? ¿Será más eficiente? Explica y justifica suficientemente tu
respuesta.

Lo más seguro es que no, pero serían igual de eficientes, ya que la complejidad asintótica y el orden de crecimiento son los mismos.
