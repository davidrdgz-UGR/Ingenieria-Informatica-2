1.- (2,5 puntos) Responde a las siguientes preguntas relacionada con la eficiencia de algoritmos:
    a. (1 puntos) Enumera y explica suficientemente que notaciones existen para la
    complejidad asintótica.

    O -->  Es la cota superior, y se basa en que el algoritmo no crece más rápido que f(n) a partir de un tamaño grande.

    Ω --> Es la cota inferior, y se basa en que el algoritmo crece al menos como f(n).

    Θ --> Es la cota ajustada y se basa en que el algoritmo describe exactamente el orden de crecimiento de f(n).


    b. (1,5 puntos) Dado el siguiente algoritmo:

    void Insercion(int numbers[], int array_size) {
        int i, a, index;
        for (i=1; i < array_size; i++) {
            index = numbers[i];
            a = i-1;
            while (a >= 0 && numbers[a] > index) {
                numbers[a + 1] = numbers[a];
                a--;
            }
        numbers[a+1] = index;
        }
    }

    a. (1 puntos) ¿Que eficiencia tiene el método? ¿Por qué? -> Dependiendo de si está ordenado el array o no puede ser O(n) o O(n^2).

    b. (0,5 puntos) Si el algoritmo anterior lo programo en Java, ¿Será más rápido que
    el proporcionado en C++? ¿Será más eficiente? Explica y justifica
    suficientemente tu respuesta.

    Eficientemente sería igual, ya que el algoritmo es el mismo, otra cosa sería cuál lenguaje es más rápido (por lo general C++), ya el tiempo depende también de las constantes externas, en este caso el lenguaje es una de ellas.
