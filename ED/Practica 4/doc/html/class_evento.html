Detailed Description

TDA Evento.

Representa un suceso asociado a una fecha (día/mes/año) y una descripción textual. Se usa como elemento almacenado en el ABB (AgendaEvento), ordenándose cronológicamente mediante el operador < (por fecha).

Invariante (validación básica):

  • 1 <= mes <= 12
  • 1 <= dia <= 31
  • anio > 0 (según criterio del proyecto)
