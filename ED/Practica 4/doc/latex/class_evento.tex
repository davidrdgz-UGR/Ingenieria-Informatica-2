\doxysubsection{Detailed Description}
TDA \doxylink{class_evento}{Evento}. 

Representa un suceso asociado a una fecha (día/mes/año) y una descripción textual. Se usa como elemento almacenado en el ABB (\doxylink{class_agenda_evento}{Agenda\+Evento}), ordenándose cronológicamente mediante el operador \texorpdfstring{$<$}{<} (por fecha).

Invariante (validación básica)\+:
\begin{DoxyItemize}
\item 1 \texorpdfstring{$<$}{<}= mes \texorpdfstring{$<$}{<}= 12
\item 1 \texorpdfstring{$<$}{<}= dia \texorpdfstring{$<$}{<}= 31
\item anio \texorpdfstring{$>$}{>} 0 (según criterio del proyecto) 
\end{DoxyItemize}
