\doxysubsection{Detailed Description}
\doxylink{class_agenda_evento_1_1_iterador}{Iterador} inorden para recorrer el árbol en orden cronológico. 

Implementa un recorrido inorden (izq, nodo, der) usando una pila enlazada propia, sin STL, para devolver los eventos de menor a mayor fecha.
